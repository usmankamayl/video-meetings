# Nest.js API

## Описание

Серверная часть приложения для видеовстреч на Nest.js.

## Запуск

```bash
# Разработка
npm run dev

# Сборка
npm run build

# Продакшн
npm run start:prod

# Линтинг
npm run lint

# Тесты
npm run test
```

API запускается на http://localhost:3001

## Endpoints

- `GET /` - Приветственное сообщение
- `GET /health` - Проверка состояния сервиса
