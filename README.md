# Video Meetings Monorepo

Монорепозиторий для проекта видеовстреч с клиентской и серверной частями.

## Структура проекта

```
video-meetings/
├── apps/
│   ├── web/          # Next.js приложение (фронтенд)
│   └── api/          # Nest.js приложение (бэкенд)
├── packages/         # Общие пакеты (будущее)
└── turbo.json        # Конфигурация Turborepo
```

## Технологии

- **Turborepo** - для управления монорепозиторием
- **Next.js** - фронтенд приложение
- **Nest.js** - бэкенд API
- **TypeScript** - типизация
- **ESLint** - линтинг
- **Prettier** - форматирование кода

## Установка

```bash
npm install
```

## Команды

- `npm run dev` - запуск всех приложений в режиме разработки
- `npm run build` - сборка всех приложений
- `npm run lint` - проверка кода линтером
- `npm run format` - форматирование кода
- `npm run clean` - очистка артефактов сборки
